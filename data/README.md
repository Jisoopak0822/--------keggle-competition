# Input data (not published)

Download the seven original CSV files from the official Kaggle competition page **only if you are authorized to access them** and place them in this directory before running the training script.

- `assessment_history_train.csv`
- `assessment_history_test.csv`
- `building_details_2015.csv`
- `building_details_2016.csv`
- `building_details_2017.csv`
- `building_details_2018.csv`
- `building_details_2019.csv`

**Do not commit the CSVs or ID-level prediction files.** The dataset is associated with a private course competition and may have redistribution restrictions.
